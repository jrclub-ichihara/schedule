# 送迎ドリル WORLD

チームの中学生向けの、定期テスト対策ドリルです。送迎の車の中や待ち時間の5分で1セットできます。
正解するとコインがたまり、「ブロックワールド」で着せかえや家づくりに使えます。

- 公開ページ（Claude のアーティファクト）：https://claude.ai/artifact/DC4HHAi8UAeVSvnJs2zivr
- このフォルダは、そのページの**元ファイルの保管場所**です。GitHub Pages では公開していません。

## できること

| 機能 | 内容 |
|---|---|
| テスト範囲モード | 英語・数学・理科・社会（中1〜中3）の単元を「ここから〜ここまで」で選んで出題。まちがえた問題は次に多めに出る |
| コーチの範囲セット | ページの持ち主だけが使える画面。範囲を入力すると Claude が4択問題の下書きを作り、確認してから公開すると子どもの画面に出る |
| 今日の5分 | 学年別のクイズ、英単語の聞き流し、部活の練習記録 |
| ブロックワールド | 先生クイズ・アスレチックでコイン、きせかえショップ、ブロックの家づくり |

記録やコインは、それぞれの端末のブラウザの中だけに保存されます。どこにも送信しません。

## フォルダの中身

```
drill/
├─ src/                 元ファイル（ここを直す）
│  ├─ head.html         見た目（CSS）と画面の骨組み
│  ├─ extra.css         テスト範囲モードの見た目
│  ├─ base.html         ロビー・クイズ・記録などの元のプログラム
│  ├─ w1.js 〜 w4.js    3Dワールド（描画・キャラ・島・操作）
│  ├─ u_data1.js        英語の単元と問題
│  ├─ u_data2.js        理科・社会の単元と問題
│  ├─ u_logic.js        数学の単元（問題を自動で作るプログラム）
│  ├─ u_ui.js           テスト範囲モードとコーチ用の画面
│  ├─ sets.json         コーチが公開した範囲セット（ページに入れこむ）
│  └─ skel_reset.txt    アーティファクトの外枠のCSS（自己公開用）
├─ tools/
│  ├─ build.py          src から dist/world.html を組み立てる
│  ├─ check_questions.js 全問題と数学の問題作りを自動チェック
│  └─ test_*.js         ブラウザで動かして確認するテスト（Playwright）
└─ dist/world.html      組み立て済みのページ（アーティファクトに公開するもの）
```

## 直し方

```bash
python3 tools/build.py              # dist/world.html を作る
node tools/check_questions.js .     # 問題データのチェック
node tools/test_range.js .          # テスト範囲モード＋コーチ公開の確認
node tools/test_flow.js .           # ワールド・家づくりの確認
```

### 問題を足すとき

`src/u_data1.js`（英語）や `src/u_data2.js`（理科・社会）の単元に、次の形で1行足します。

```js
['問題文', '正解', 'まちがい1', 'まちがい2', 'まちがい3', '解説'],
```

足したら `check_questions.js` で、正解とまちがいが重なっていないか確かめます。

## 大事な注意

- **コーチが公開した範囲セットは、公開中のページの中に保存されています。** ここから組み立てたページを公開しなおす前に、公開中のページの `<script id="sets">` の中身を `src/sets.json` にコピーしてください。そうしないと範囲セットが消えます。
- 単元の名前と順番は一般的な中学校の教科書に合わせています。教科書会社によって少しちがいます。
- 他のゲームの名前・キャラクター・画像・音は使っていません。絵や音はすべてプログラムで作ったオリジナルです。
