# 顔の見分け：サーバー（GAS）側で必要な変更

画面側（このリポジトリ）は対応ずみです。GAS のコードはこのリポジトリに入っていないので、以下を GAS に足してください。
顔の計算はすべて端末の中で行います。GAS は「数字（特徴）と名前を保存して返すだけ」で、外部のAIサービスには何も送りません。

## 1. `saveAlbumPhoto(PASS, meta, full, thumb, faces)` — 顔に新しい項目が増えます
`faces` の1つ1つ：

| 項目 | 意味 | 今まで |
|---|---|---|
| `d` | 特徴（128個の数をカンマでつないだ文字） | あり |
| `c` | 顔の小さい画像（96px） | あり |
| `n` | 確定した名前（自信があるときだけ。ないときは空） | あり |
| `q` | **新** 候補の名前（「◯◯？」で出す。自信がないとき） | — |
| `p` | **新** 自信 0〜100 | — |
| `y` | **新** 横顔の度合い 0（正面）〜1（真横） | — |
| `w` | **新** 顔の幅（元の写真のpx） | — |
| `how` | **新** `'自'`＝自動で付いた名前 | — |

→ `q` `p` `y` `w` `how` もそのまま保存してください。

## 2. `getPhotoFaces(PASS, photoId)` — `q` も返す
アルバムで「◯◯？」と出し、「はい、◯◯です」で決められるようにするため。
`fixPhotoFace(PASS, faceId, n)` で名前を決めたら、`q` を空にして `how='手'` にしてください。

## 3. `getUpInit(PASS)` の `refs` — 「1人1つ」→「名前が確定した顔ぜんぶ」
```
refs: [{n:'名前', d:'0.12,-0.03,...', how:'手'|'自'}, ...]
faceExclude: ['外す子の名前', ...]
```
- 人が付けた・直した顔（`how='手'`）はぜんぶ入れる → **直した名前が次から見本になる**
- 自動で付いた顔（`how='自'`）は、自信 `p>=80` で正面（`y<0.4`）のものだけ
- `n` が空・`'対象外'` の顔は入れない
- 1人あたり最大30個まで（人が付けたもの優先・新しい順）。多すぎると古いスマホで重くなるため
- 画面は前回の `getUpInit` を先に使い、裏で取り直した新しい見本に差しかえます

## 4. 新しい関数 `getFaceBank(PASS, ADMIN)` — まとめて名前付け画面（faces.html）用
```
{ roster:[{name,no}], isAdmin:true|false, exclude:['名前',...],
  faces:[{id, d, n, q, c, w, how}, ...] }
```
- `faces`：名前のない顔（新しい順に最大1500）＋ 3. と同じ見本の顔
- 非表示にした写真の顔は入れない
- パスコードがちがうときは `{needPass:true}`

## 5. 新しい関数 `setFaceNames(PASS, [{id, n}, ...])`
まとめて名前を保存。`n` は名前か `'対象外'`。保存するとき `how='手'`、`q=''`。
写真の「写っている子」（アルバムの「選手で探す」）も更新してください（`fixPhotoFace` と同じ処理を一度に）。

## 6. 新しい関数 `setFaceExclude(ADMIN, ['名前', ...])`
「顔の自動の見分けから外す子」の一覧を保存（コーチ・スタッフ用パスコードのときだけ）。
- `getUpInit` と `getFaceBank` の `faceExclude` / `exclude` で返す
- 外した子の、**自動で付いた**名前（`how='自'`）は消すのがおすすめ（人が付けたものは残す）
