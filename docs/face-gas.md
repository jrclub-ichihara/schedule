# 顔の見分け：GAS（サーバー側）の入れ方

`gas/face2.gs` を GAS に新しいファイルとして足すだけです。`コード.gs` は書き換えません。

1. 予定表のスプレッドシート →「拡張機能」→「Apps Script」
2. 左の「ファイル」の **＋** →「スクリプト」→ 名前を `顔の見分け` にする
3. 中身を全部消して、`gas/face2.gs` の中身を貼り付けて 💾 保存
4. 「顔の見分け」がファイル一覧の **いちばん下** にあることを確認（`コード.gs` より下）
5. 上の関数の選択で `faceSetupCheck` を選んで「実行」→ 実行ログに「OK」が3つ並べば準備完了
6. 「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」（URLは変わりません）
7. そのあと、GitHub の `main` に画面側の変更を入れる

## 変わること
- 見本が「1人1つの平均」から「名前が確定した顔ぜんぶ（1人20個まで、手で付けた顔が優先）」に
- 名前を直すと、すぐ次から見本になる
- 自信がない顔は「候補（◯◯？）」として「顔データ」シートの G〜J列（候補・自信・横顔・顔の幅）に保存
- 新しい関数 `getFaceBank` / `setFaceNames` / `setFaceExclude`（まとめて名前付けページ用）
- 「見分けから外す子」は、スクリプトのプロパティ `FACE_EXCLUDE` に保存。外すと、その子の**自動で付いた**名前と候補は消えます（手で付けた名前は残ります）
- 前の「顔の名前付け」ページ（`?mode=faces`）は新しいページへ移動します

## 元に戻すとき
「顔の見分け」ファイルを削除して、もう一度「新バージョン」でデプロイすれば、前の動きに戻ります（G〜J列は残っても問題ありません）。
