# Jr.CLUB市原 サイトの見た目の決まり（2026/11〜）

ハコトト「チーム版」のデザインの決まり（`hacototo/hacototo-app` の `docs/design-team.md`）を、今のサイトに当てはめたもの。
画面を作る・直すときは、このファイルを読んでから。

## ファイル
| ファイル | 中身 |
|---|---|
| `club.css` | 色・文字・部品・動きの速さ。**全ページで、ほかの CSS のあとに読み込む**。今までの色の名前（`--y` `--ink` `--disp` など）も、ここで新しい色につないでいる |
| `club-fonts.css` | 見出しの英字・数字の文字（Barlow Condensed・SIL Open Font License）。手で直さない |
| `club.js` | 動きの部品（開いたときのロゴの動き・上の動く絵・線で描くロゴ）。hacototo-app の `prototype/team/team.js` と同じもの。**直すときは両方に同じ変更を入れる** |
| `club-page.js` | 全ページの下のメニューを付ける。予定表以外のページでは、見出しのロゴを線のロゴにして、開いたときの動きも出す |

## 色
- 黒地にクラブの黄色（`--brand: #ffeb3b`）。黄色は「ここを見て」「これを押して」のしるし。飾りで広く塗らない
- 済み・注意・期限切れなどは、黄色とは別の色（`--ok` `--warn` `--danger`）。色だけでなく言葉も添える
- 土曜は青（`--sat`）、日曜・祝日は赤（`--sun`）。土日祝のカードは地とふちの色を変える
- 「表で見る」は、今までどおり白い紙に黄色の土日祝（画像で保存して配るため）

## 文字
- 見出し・月・日付・背番号・得点：Barlow Condensed の太字の斜体（`--font-display`）
- 本文：端末の標準の文字。16px 以上（補足は14px、ラベルは12pxまで）。日本語の文章は斜体にしない

## 動き
- **開いたときのロゴの動き**：クラブのロゴの動画と同じ流れ（パーツが飛んでくる→光る→六角の輪と火花→ICHIHARA→上のロゴへ飛ぶ）。動画ファイルは使わず、`club.js` が線で描く
  - その日はじめて開いたときだけ長いほう（約2.6秒）。同じ日の2回目からは短いほう（約1秒）。同じ訪問の中では出さない。画面を押すとすぐ飛ばせる
  - どのページから開いても同じ決まり（`jr_intro_day` と `jr_intro` で共通）
- **予定表の上の動く絵**：ボール・コートの線・リング・光だけ。選手や子どもの姿は描かない
- **止める条件**：端末の「動きを減らす」設定、通信量の節約、とても遅い回線。動く絵は止まった1枚になり、開いたときの動きも出さない
- キャラクターは使わない（2026/11 ヘッドコーチの判断）

## 下のメニュー
- 全ページの下に4つ：**予定表・お休み・選手・アルバム**（`club-page.js` が付ける。クラスは `.bnav`。アルバムの写真の矢印 `.nav` とぶつからないよう別の名前）
- 写真アップ・顔の名前付けのページでは「アルバム」を光らせる
- ハコトトに移ったときは、5つ目に「お金」が増えるだけ。**順番と名前は変えない**
- 今までの「‹ SCHEDULE 予定表にもどる」や、予定表の中の 3POINT・ROSTER・ALBUM、いちばん下のリンクも残す（慣れている保護者さんのため）

## 予定表（index.html）
- 中身は GAS（`?api=schedule`）が作って送ってくる。GAS の部品（`.day` `.row` `.tag` `details` など）の形は `club.css` の「3. 予定表」で整える
- 試合の結果（WIN／LOSE）は、GAS が色を直接書いてくるので、`index.html` で `.result` のしるしに置きかえている
- 「NEXT GAME」：今月の、今日から先でいちばん近い試合を出す。押すとその日の詳しいところが開く
- 月のタブ・カード／表・試合を押すと詳しく・今日へ移動、の使い方は今までのまま

## 守ること
- 保護者さんが迷わないよう、場所・言葉・使い方を勝手に変えない
- スマホの幅（390px）で横にはみ出さない。押すところは高さ44px以上
- 新しい色や大きさを、画面ごとに書き足さない。`club.css` の名前（`var(--brand)` など）を使う
